3. Task-id collisions between lanes: "anything we can do here?"
4. Tests that couldn't fail: "not sure we can do anything on this."

6. The "one step late" fidelity gaps: "is there a root cause to this?"

To the session's proposal (a measured survey, a crate split for his approval, the splits one at a time, a stand-in ledger, per-lane id blocks, item 6 fixed by AH.59 ahead of AH.25): "yes write the change, we should also consider caching things like the intro transcoding or other things that might be overtesting".

## What Changes

- **Per-lane id blocks** (item 3), in [`openspec/config.yaml`](../../config.yaml) with this proposal (AQ.1): the session hands every lane it launches, a lone one included, a block of new task ids per change, written into its prompt; a lane numbers new boxes only from its block and lists any past it unnumbered for the merge; a new change id goes out the same way; unused ids stay gaps; the session with no lane out takes the next free id.
- **A stand-in ledger** (item 2): every stand-in in the design tables, the backlog, the open boxes and the code, each with the box that retires it (a box added where none exists) and the hazard of leaving it in, the hazardous ones ordered ahead of the box they'd break, the swap's script reinstall first and ahead of AH.25.
- **Two measured surveys** (items 1 and 5, and chotchki's caching ask): the code (every file over 1,000 lines with its conflict history, `cargo build --timings` per crate cold and after a one-line change in each hot file, guacamole's module graph, which test binaries each hot file drags into a rebuild) and the test time (per-test durations, every repeated expensive setup with its cost and a verdict, the intro transcodes first, and tests that exercise the same thing twice). Each ends in a proposal: crate and file boundaries, a cache and narrowing list.
- **chotchki approves** the split and the cache list before anything moves. The 1,000-line mark is a trigger to consider a split, not a rule. He did at AQ.5 (2026-10-23): "I'm good with AQ.5's recommendations", every one as written, which settles the next two bullets.
- **No crate split now; build plumbing, then the moves a merge or a cycle asks for.** The trial crate (the hero and physics, out of the binary) built 0-0.5 s faster and tested 2.2 s slower, since cargo's dependencies are per package, and a file's size doesn't predict its rebuild, so the time is in the plumbing: one Bevy for guacamole's build and tests (a manifest line and a guard against its drift), [`crates/guac-extract/tests/giants_roster.rs`](../../../crates/guac-extract/tests/giants_roster.rs) into guac-server's tests, persistent lane worktrees, `doctest = false` on the 16 libraries with none. Then, one at a time, moves only, each when no lane is editing its files: the shared test helpers out of the hot files, the mirror composing what each subsystem reports, [`tv.rs`](../../../crates/guacamole/src/tv.rs)'s shared state below the screens, and the binary's other cuts on AH.59, which has landed; crates come back only after the cuts. guac-script's [`vm.rs`](../../../crates/guac-script/src/vm.rs) and guac-server's two stay whole (never conflicted).
- **Test time.** `TMPDIR` on a 2 GiB APFS RAM disk for test runs, since the drive flush was the biggest cost, once oracle-harness's lock test stops racing on it; the e2e building its binaries once; inputs a test needs but doesn't test shared once per test binary (the e2e's intros; the VM disc tests' read and link of the dump's script part, in memory); nothing kept across runs (the intro and synthetic-extract caches turned down: ~0.7 s and ~1.5 s beside the RAM disk); anything a test exists to exercise never shared; five tests that covered the same thing twice removed, two after a narrower test takes their one unique catch, the mutants the removed ones caught still caught; AC.13's captures a key of their own, so every disc test runs in one command.
- **Item 6 stays AH's**: AH.59 is the root cause, promoted ahead of AH.25 in [`ah-first-fight/tasks.md`](../ah-first-fight/tasks.md) with this proposal (measure the original's per-frame order on the oracle once, encode it as one explicit Bevy schedule of named sets every system joins). AH.25 now stands on it.
- **Out:** any behaviour change (a split is moves, a cache feeds inputs, a narrowed test keeps its coverage); a requirement or spec; a Bevy or dependency upgrade; the product's behaviour (no guac-server split; the boxes that reach guac-server's or the product's manifests and tests change nothing they ship).

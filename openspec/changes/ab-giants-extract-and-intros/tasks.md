Layout read off Giants' own archives by a read-only probe outside the tree, cross-checked against igRewrite8's `igArchive.cs` and IGAE's version table: the header after magic and version is TOC size, file count, sector size (0x800), hash-search divider (0xFFFFFFFF / count) and slop (the furthest hash / divider lands from its index), name-table offset and size, large, medium and small block counts, flags (0), all 893 alike; the TOC size is exactly count x 16 + large x 4 + medium x 2 + small; the name table is the file's tail and every name has a nonzero u32 after its NUL; a compressed entry's size picks its block table (small up to 0x7F sectors, medium up to 0x7FFF, large past that), slot j is chunk j's start in sectors from the entry's offset with the top bit meaning compressed, and slot j + 1 its end; a chunk LZMA would grow is stored raw, 1,384 of them. LZMA crate: lzma-rust2 0.23 over lzma-rs 0.3. Both pass decision 2's two tests (raw props plus a known unpacked size, no header; 200k mutated real chunks, no panic, and both decode all 213,560 of Giants' LZMA chunks to identical bytes). lzma-rust2 won on speed (145 s vs 215 s for the whole disc, release, one thread), on having a real encoder for the test writer (lzma-rs writes literals only) and on a strict end check every Giants chunk passes, so a stream longer than its declared size errors as well as a short one; with default features off it's `forbid(unsafe_code)` and has no dependencies. The reader refuses lc + lp > 4 and clamps the dictionary to the chunk, so one chunk holds under 128 KiB. Other versions are refused naming the version: Trap Team's little-endian v0x0B, and the big-endian `\x1aAGI` archives of Swap Force, SuperChargers and Imaginators. fmt and clippy --workspace --all-targets -D warnings clean, `cargo test --workspace` 411 passed + 43 ignored (+15: 12 reader, 3 writer; +1 ignored, the disc test).

# Guacamole dev environment

Every env key, path and CLI entry a Guacamole dev session reads: running `guacamole` from cargo, the RE paths the disc tests need, and the oracle. Moved out of [`CLAUDE.md`](../../CLAUDE.md) on 2026-11-13 to keep that file small; it keeps the handful of keys every session needs and points here. The example values live in [`.env.dev.example`](../../.env.dev.example).

- **guacamole:** `cargo run -p guacamole` from the repo root (add `--features test-hooks` for `/api/_test/*`). It reads the same `.env.dev`, and the keys that matter are `GUAC_DUMP_DIRS` (dump folders in the OS's path-list form; set, it overrides the stored folders and the TV skips setup), `GUAC_EXTRACT_DIR` (the extract root outside the tree; unset, a Giants pick extracts nothing and plays no intros), `GUAC_FFMPEG` (ffmpeg's path, over the stored `ffmpeg_path`; unset, discovery tries beside the executable, PATH, then Homebrew's bin folders on macOS), `GUAC_OUTPUT_LATENCY_MS` (how far intros hold their video back for the sound path, 0-1000, over the stored setting; default a provisional 43), `BIND_PORT`, `DATA_ROOT` and `WINDOW_MODE` (it also reads `PHONE_DIST`, which nothing uses: the phone comes from `rust-embed`) — never `RPCS3_EXE` or `FIRMWARE_PACK_ROOT`. A `test-hooks` build also reads `GUAC_TEST_KNOWN_DUMP` (`<TITLE_ID> <APP_VER> <manifest hash>`: the synthetic dump the e2e harness writes into its own scratch `.env.dev`, trusted beside the known-dump table; never set by hand). Process env, not `.env.dev`: `GUAC_MUTE` (any value mutes intros and the level's sounds in a dev build, the sounds' game side running the same), `GUAC_TEST_POSTED_PADS_ONLY` (any value, `test-hooks` builds only: no gilrs and no GameController pads, so only `/api/_test/tv/pad`'s pads connect and a paired pad can't walk the hero first; the e2e harness sets it with `GUAC_MUTE`), `GUAC_TEST_UNMODEL` (`test-hooks` builds only, AG.221: one registered member's name as `namespace.name`, e.g. `collisioninfo.object collisions`, taken out of the TV's run at every install through guac-script's `Members::without`, so a walker whose script reaches it stops in play there and falls back (that one: the eight Giants' twelve files, at `Minion.ai` #842 with the stick on); a name the registry doesn't hold, one it only keeps by name, one lacking a half or an empty one logs an error and installs the run unchanged; the member taken out is logged at the install), `GUAC_TEST_JUST_DONE` (`test-hooks` builds only, the au-polish review: adventures by their place in `adventure data`, comma-separated, marked just done on a run whose start loaded the host's stored save, as a level end leaves them, so a resume reaches a first visit's scenes; `2` brings the Hermit's scene and its movie to the hub after level 201), `GUAC_LEVEL` (a level's archive name, `dev-tools` builds: AS.13's level by name asked at start, as `/api/_test/tv/level` asks it, loaded once the Giants pick's extraction ends), `GUAC_LEVEL_VIEW` (any value: once the Giants pick has loaded chapter 1, a dev build draws it over the TV at AF's fresh-state camera, AG.19's dev entry, with no hero: a level it shows is no longer one the walk can enter; a level asked for by name it draws at its start as that camera frames chapter 1's, AS.13, and `/api/_test/tv/camera` holds that view too), `GUAC_DEV_ENTRY` (`b`, `start`, `end`, `pods`, `elves`, `part`, `part2`, `door2` (AS.97: past level 214's second door) or `interior:<controller>` (AS.96: outside any level's interior's door), any dev-tools build: AH.25's dev entry asked at start, as `/api/_test/tv/entry` asks it; the first fight's four Chompies, Setup_001's controller and Norticus from their scripts, the creatures drawn on their models off the props part in the tint their scripts leave (a beaten Chompy fading, AH.139) and walked as bodies in Avian's world beside the hero's, [`creatures.rs`](../../crates/guacamole/src/creatures.rs), the orbs they leave drawn by their own emitters' glow, [`orbs.rs`](../../crates/guacamole/src/orbs.rs) keeping an entity each, AH.61, AH.350) and `GUAC_SHOT_DIR`, which renders the TV offscreen to PNGs; it must be outside any git checkout (intro shots are game frames), and one inside is refused; one that isn't there is made, and a shot that fails to write logs an error (AE.29). With it, `GUAC_SHOT_YAW` (degrees, default 0) is where on its turn each card's model holds still, and `GUAC_SHOT_WALK=<ms>` adds a shot every that many milliseconds the hero has moved while he walks, and as often while anything his attacks spawned draws, named `attack`, each naming the scripts' step it was drawn at (AG.21, AH.24, AG.79; off by default, since a shot's PNG is written on the frame's thread). The extractor's CLI: `cargo run -p guac-extract -- identify|census|intros|transcode <dump>` (reads `GUAC_EXTRACT_DIR`, `GUAC_FFMPEG`, `GUAC_FFPROBE` from the env, else `.env.dev` in the current folder). Release build + run on the Mac: [`docs/native/guacamole-design.md`](../../docs/native/guacamole-design.md) (Running guacamole on the Mac).
- **Guacamole RE paths** (dev only, both outside the tree): `GUAC_GIANTS_DUMP` is the Giants (BLUS30968) dump root, the folder holding `PS3_GAME`; the `#[ignore]`d disc tests in `crates/guac-formats/tests/` and `crates/guac-extract/tests/` and the `hero_view` example read it from the process env, else `.env.dev`. Of guac-extract's, `giants_identity`, `giants_intros` and `giants_transcode` make a throwaway extract under `GUAC_EXTRACT_DIR` (the transcode also needs ffmpeg and ffprobe), and `census_dumps` writes its report into `GUAC_EXTRACT_DIR`, needs ffprobe and takes every `GUAC_*_DUMP` key plus `GUAC_CENSUS_DUMPS` (a path list of dumps, or of folders holding them up to two levels down). `GUAC_CAPTURE_DIR` is the captures root, where RSX captures, savestates, recordings and `rrc-dump --out` output go (each under its `BLUS30968/` folder), and every test reading a recording reads it there. [`crates/guac-formats/tests/giants_capture.rs`](../../crates/guac-formats/tests/giants_capture.rs) (AC.15-AC.17) and [`crates/guacamole/tests/remaster_gpu_lane.rs`](../../crates/guacamole/tests/remaster_gpu_lane.rs) (AE.12) read AC.13's session from `GUAC_AC13_CAPTURE_DIR` (`captures/BLUS30968/09d602fd5/session-20261018`), its three captures and frame 4 by name, so other captures landing there don't change what they compare (AQ.37: a key of its own, so every RPCS3-free disc test runs in one command); `rrc-dump` refuses any output dir inside a work tree of this repo and its error points at `$GUAC_CAPTURE_DIR` ([`tools/rrc-dump/src/output.rs`](../../tools/rrc-dump/src/output.rs)). [`crates/guac-formats/tests/giants_capture_texels.rs`](../../crates/guac-formats/tests/giants_capture_texels.rs) (AC.21) reads its four upgrade-art captures by name from `GUAC_AC21_CAPTURE_DIR`, its own key the same way. All five keys are in [`.env.dev.example`](../../.env.dev.example). Process env only, guacamole's disc harness ([`crates/guacamole/tests/common/mod.rs`](../../crates/guacamole/tests/common/mod.rs)) prints two censuses: `GUAC_SURFACE_CENSUS` (AS.168) each clone standing for actors and the step the hero first comes near it, `GUAC_HANG_CENSUS` (AS.189) each let-go of the hero, what he hung from, where, and where he is 60 steps on.
- **The oracle** (dev only, Mac only until the Windows/HTPC bring-up, every path outside the tree): `GUAC_ORACLE_EXE` is the oracle binary (`.../RPCS3.app/Contents/MacOS/rpcs3`, where `rpcs3-patches/oracle/build.sh` installs it) and `GUAC_ORACLE_HOME` its isolated HOME (`oracle home init` builds it from the dev's RPCS3 dir; a savestate boots only in a home holding its trophy files, `dev_hdd0/home/00000001/trophy/NPWR03657_00` from the home it was taken in, which init doesn't copy). `GUAC_ORACLE_SAVESTATE` is a gameplay state this build accepts (what `live_pine` boots, and `live_pad`, `live_rng`, `live_actors` and `oracle divergence run` replay); `GUAC_ORACLE_FIGURE` the `.sky` `live_gameplay`, `live_verbs`, `live_pad`, `live_rng`, `live_actors` and the runner copy onto the portal, fresh each boot; `GUAC_CAPTURE_DIR` also takes the output of the live tests that write any (`live_verbs`, `live_pad`, `live_rng`, `live_actors`: `$GUAC_CAPTURE_DIR/BLUS30968/<af…>-<unix time>/`, `run.txt` opening on the identity line), while the runner writes where `--out` says; `GUAC_ORACLE_DIVERGENCE` and `GUAC_ORACLE_CALIBRATION` are AF.11's and AF.12's output dirs the `#[ignore]`d `calibration` test reads, and the `#[ignore]`d `anchor_a` test (AH.51) reads AH.9's replays by name under `GUAC_CAPTURE_DIR` (or its `BLUS30968/`). All of those from the process env, else `.env.dev`, and the live tests also need `GUAC_GIANTS_DUMP`. Process env only: the live tests' `ORACLE_READY_SECS`, `ORACLE_SAMPLE_SECS`, `ORACLE_LEVEL_SECS` and `ORACLE_IDLE_SECS` (waits), `ORACLE_SHADER_MODE` (the home's shader mode) and `ORACLE_AUDIO` (sound on; silent by default), and `GUAC_FLIP_REF`, the NVlabs/flip clone `guac-oracle`'s `#[ignore]`d `flip_reference` reads. `cargo run -p oracle-harness --bin oracle` prints the CLI (`home init`, `boot`, the O-verbs, `pad-load`, `pine`, `rng`, `actors`, `goto`, `session`, `divergence run|report|calibrate|check`); `session --plan <plan.ron>` (AG.6) cold-boots a home (or a state, or attaches to `boot --hold`) and runs menus, figures and both pads with the game running, every guest file it opens stamped with the flip; `goto --route <route.ron>` (AH.7) drives a fresh boot to a point closed loop, pausing every few flips to steer through O4, and can save the state it settles in (`--sched`, AH.59, records the script scheduler's lists every frame); `divergence run --perturb <change>` makes AF.12's perturbed walks, `--place <name>[=<variable>,...]` (AG.176, sets W and O) puts level 213 placements on O5's list (where each stands, its wake state, behaviour and clock and the named script numbers, every frame, `places.json`), and `--gap-secs` (30) waits after each RPCS3 exits, because a boot straight after one hangs on a CoreMIDI client error; the runner stops if a replay changes the home's saves or trophies, which a state's load doesn't put back. Never connect to the oracle's GDB stub (2346): a connection pauses it. Close a PINE connection before any `SAVESTATE` or shutdown: an open one blocks every stop.
